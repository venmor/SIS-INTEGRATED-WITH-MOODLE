# Contributing

Work from a branch or isolated worktree; do not push directly to `main`. Every implementation task starts with a handbook-linked task packet and ends with peer review, verification evidence, a learning note, and an updated traceability record when applicable.

Charles Hangoma and Chitindu Milimbo rotate full vertical-slice ownership. The lead implements and presents the slice; the reviewer challenges source assumptions, adds denial/failure/recovery/accessibility coverage, reviews the pull request, and records evidence. Swap these roles for the next slice.

Use only fictional fixtures. Keep commits focused and do not add dependencies or change architecture without an approved ADR.
