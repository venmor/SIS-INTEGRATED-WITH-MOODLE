# V2-ADM-002 — exact case-reference search, 2026-10-02

The admissions queue now accepts an exact reference filter in both existing reviewer views. Search happens in PostgreSQL under the same live assignment and intake/claim predicates as pagination. The URL retains the reference for refresh and saved links; changing the search starts at page one. A foreign, peer-claimed or missing reference has the same empty response, and the UI says only that no case matched this queue. The cursor binds the normalized reference. No applicant identity or evidence was added to queue rows.

The initial API test failed with 400 before the parameter existed, then exposed the mixed-case UUID reference after the first implementation; case-insensitive equality corrected that. Browser search passed at 390px. The full existing browser journey initially assumed its newly submitted case would be on the first page; the real large synthetic intake showed why that assumption fails. It now finds its own case by reference. Repeated seeded-officer sign-ins then reached the existing security rate limit; distinct synthetic officer fixtures let all journeys run without changing that policy. A separate harness failure came from the worktree `.env` API port 3147 versus Playwright's 3101; the final run set `PORT=3101` in the process environment.

Focused results on isolated `sis_v2_review_20261002`: API queue **15/15** and setup combined **19/19**, browser admissions **4/4**, API/web production builds, TypeScript typecheck, lint, scan and diff checks passed. No package, image or dataset download was needed. The synthetic database retains immutable test submissions. On 20,199 applications, `EXPLAIN (ANALYZE, BUFFERS)` for a missing case-insensitive reference initially showed a sequential scan (18.839 ms, 667 shared-hit buffers); after the additive `pg_trgm` GIN migration it showed a bitmap index scan (0.660 ms, 37 shared-hit buffers). These are local single-query observations, not a production service target. Real migration lock/size planning, concurrent staff load, manual accessibility and institution-approved scope graph remain open. This is a workbench search increment, not complete high-volume admissions allocation or v2.0 acceptance.
