# V2 admissions assigned-case preparation preview — 2026-10-02

`TASK-V2-ADM-004` adds a bounded, read-only preparation preview for up to 50 cases claimed by the active admissions officer. Each selected case is checked against the current role assignment, `review-assigned` capability, intake scope, claim and application version. A released, foreign, out-of-scope or unknown case returns the same `UNAVAILABLE` shape; a stale version returns `CHANGED` without document details. Current rows expose only reference/version, current file-state counts and open clarification/correction counts. Document presence does **not** certify quality, completeness, eligibility or admission. The response is not saved as an official review finding. The preview access itself writes an audit event; it does not alter applications, assignments or decisions.

The officer selects cases on one loaded queue page. Selection clears on successful refresh, filter, sort, page or view change, and on authorization loss. Stale queue data blocks preview. A failed preview leaves the selection available for a safe retry and says no case was changed. The result directs officers to individual case evidence. No applicant name, contact, file bytes or possible-duplicate identity is included.
