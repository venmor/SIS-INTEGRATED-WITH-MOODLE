# Admissions batch and reference-led staff UI

The admissions officer can select up to 50 displayed cases and claim them using the existing per-case command. Every case has an independent stable idempotency key, expected version and confirmed or recoverable outcome. Pause completes the in-flight request; resume reuses uncertain keys; loss of authority clears retained private results. Navigating away stops subsequent claims. This supports fast work without implying an atomic decision over an entire intake.

The staff shell follows the selected emerald-sidebar, white-topbar and pale-canvas references. Assessment plans and grade batches use task panels, compact labelled entry grids, functional filters over loaded records, and accessible mobile labels. Reset preserves success feedback; technical administrators see the correct read-only capability hint. Existing academic approval, staging and audit contracts remain unchanged.

A connected regression exposed two underlying defects. Lecturer/moderator and examination readers previously selected records without their exact offering/period scope; predicates now precede pagination and also guard direct reads. Detail and approval pages previously searched a 200-row registry, incorrectly hiding a known record outside that window. Direct scoped plan and mapping endpoints now retrieve known IDs independently of registry size. Scope-test fixtures clean only their own exact records.
