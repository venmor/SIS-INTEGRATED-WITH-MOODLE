# V2-APP-001 — applicant document handoff, 2026-10-02

The local applicant walkthrough exposed two separate submission blockers: a qualification document remained in `SecurityScanPending` because the demo scanner accepts only the exact fictional fixture, and a required subject result was missing. The former must not be bypassed or called verified; the latter must be corrected in the qualifications step. The document page also lacked a direct route to review and only showed progress after an XHR upload event, which could be missed on a fast local transfer or a file selection before hydration.

The document page now provides a downloadable fictional practice PDF when the exact-fixture demo adapter is active, explains that other files cannot clear the demo safety check, and gives a direct **Review application and next steps** link. It surfaces outstanding qualification requirements with a return link. Transfer progress starts when upload begins; after transfer it says the page is waiting for the saved receipt. A pre-hydration file selection is recovered from the native input. Receipt, safety check, readability and formal verification remain distinct. Server-side debug logging of applicant API payloads was removed. Existing documents were not inspected, deleted or reclassified.

Browser regressions were red before implementation: the fictional sample/next-step link was absent, and a file selected before hydration left Upload disabled. After implementation, the focused cases passed **2/2** and the connected applicant plus public applicant suites passed **9/9**, including delayed upload response and mobile application submission. API unit suites passed **309 with 13 skipped**; web production build, API/web typecheck, lint and source scan passed. The local running page returned 200, served the practice PDF, showed the subject blocker and review link, and emitted no applicant debug response log. No download or provider charge was used.

The scanner is still an exact-fixture demonstration, not a production file-safety service. Arbitrary documents remain quarantined. Manual keyboard/screen-reader and low-bandwidth rehearsal, production scanner/storage and institutional policy acceptance remain open.
