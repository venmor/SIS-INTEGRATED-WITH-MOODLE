# V2-TIME-003 — draft academic-delivery identities, 2026-10-04

[TASK-V2-TIME-003](../task-packets/TASK-V2-TIME-003.md) adds stable institutional-unit IDs with separate dated versions and typed relationship rows; course versions bound to the legacy stable course ID; period-bound course delivery offerings and sections; and physical buildings and venues. Offering rows distinguish delivering unit from campus and reference an actual academic period. Venue records separate teaching and examination capacity and leave step-free access unknown until recorded. These are additive draft identities. They do not infer a course offering from a programme application offering, a `Course.semester` label, a course-only registration or a tutorial-group `meetingPattern`.
