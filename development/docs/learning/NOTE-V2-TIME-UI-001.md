## Data and authorization

The server route forwards the existing session and optional `attemptId`/`period` to `GET /registration/timetable`. Refresh and sign-in return routes preserve that context. A successful default read redirects once to its authoritative explicit attempt/period. An explicit request cannot silently accept another returned attempt or period. Repeated context is unavailable before a timetable API call. The existing read-only `/auth/me` endpoint confirms the current STUDENT account before any recovery marker is read or written; it adds no action authority.

The published decoder requires a nonempty current registered-course projection, valid UTC timestamps and publication lineage. It checks current course membership, unique current session IDs, valid before/after history, matching change/session IDs, unique change IDs and exact agreement between an added/changed activity and its current session. A removed activity must be absent from current sessions. Malformed, empty or foreign projections fail closed and disclose neither current nor historical rooms. Backend TIME-007 remains responsible for current appointment/student/attempt/course entitlement, demo safety and immutable publication/audit.

A registered empty source remains publication-pending; pre-registration absence alone offers registration. The refresh button announces checking and retains the current page while in flight. Root's final review required closing the original date-retention gap. Session storage now contains only a valid confirmed-read ISO timestamp under an opaque SHA256 key derived server-side from account + attempt + period. No cookie/token, actor name/identifier, course, session, receipt or history is stored as a value. After a 5xx/transport failure, the current timetable disappears and the matching date marker says “Last confirmed date” and “Current timetable unavailable”. Actor/context changes, failed identity checks and foreign/malformed/access-denied responses cannot reveal the marker. A default failure before any successful authoritative context is known has no remembered date. Disabled/corrupt storage is ignored safely. This metadata never supplies entitlement or a timetable. Human screen-reader and operational recovery acceptance remain open.
