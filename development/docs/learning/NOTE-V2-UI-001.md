# V2-UI-001 — applicant UI foundation, 2026-10-02

The user requested a modern, practical SIS interface with Tailwind CSS and micro-interactions. ADR-003 records an additive Tailwind v4 layer in the web workspace: it imports theme/utilities without Preflight and maps semantic colors, radius and shadow to the existing proposed tokens. CSS Modules remain for existing screens. This is a UI implementation decision, not institutional brand or policy approval.

The applicant portal header now groups identity and task navigation with compact touch targets. Supporting documents separate file requirements, current status, upload controls, selected file, transfer progress, receipt wait, qualification blockers and the review route. The local exact-fixture warning remains explicit; a document is never presented as verified merely because it was selected, transferred or received. Nonessential color transitions stop for reduced-motion users.

The connected applicant and public-applicant browser suites passed **9/9** after the change. One first run exposed a second `role=status` on the selected-file notice; this was removed so upload feedback remains the sole live status. A synthetic 390px browser capture showed no horizontal overflow and exposed the document state and review route; its cramped native file chooser prompted a final spacing/button treatment. Production web build, API/web typecheck, web lint, source scan and formatting passed. The test database was the existing isolated `sis_v2_review_20261002`; no real applicant document was opened or reclassified. A local package audit reported a critical advisory for the existing pinned Next.js 16.3.5 along with other repository advisories; Tailwind itself was not listed. Dependency remediation and production exposure review remain separate work.

This increment covers only the applicant shell and document step. Other SIS screen families, manual keyboard/screen-reader review, low-bandwidth rehearsal, stakeholder visual acceptance and institutional palette approval remain open under Task 7 of the v2 plan.
