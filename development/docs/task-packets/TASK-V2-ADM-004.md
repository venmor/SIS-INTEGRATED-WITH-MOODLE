# TASK-V2-ADM-004 — Assigned-case preparation preview

- Release: v2.0 Task 3. Lead Charles Hangoma; reviewer Chitundu Milimbo. Human role and operational acceptance pending.
- Authority: approved v2 spec §3.2 and Task 3; `REQ-ADM-005/006`, `ACT-ADM-001`, exact Design Section 6 stages 1–4, cross-blueprint `UI-BULK-001`, UI status/recovery and permission matrix, existing TASK-PH3-001/002. Supersession and readiness registers retain the review/offer task gate.
- Scope: an officer selects up to 50 **claimed** cases from the current queue page and requests a read-only preparation preview. The API rechecks the active `ADMISSIONS_OFFICER` assignment, `review-assigned` capability, intake and live case claim. A mismatched version returns a neutral changed row; a foreign, released or unknown ID returns an indistinguishable unavailable row. No claimed case is silently skipped.
- Output: per-case reference/version for authorized current cases, counts of current document states and open clarifications/corrections, plus a plain warning that document presence is not quality or eligibility verification. No applicant name, contact, document bytes, match identity, decision recommendation, claim change or database migration.
- UI: selection count and scope visible, preview is explicitly non-mutating, selection clears on page/filter/view change and loss of authorization, stale queue blocks preview, failure preserves the current page and offers retry. The result labels changed/unavailable rows and directs individual review.
- Tests: allow, mixed foreign/unknown/released, live revocation, version change, invalid/duplicate/over-limit input, no-write proof and mobile/keyboard browser path. Existing queue and decision tests remain green.
- Exclusions: automatic completeness certification, duplicate identity scoring, bulk claim/recommendation/admit/reject, cross-school allocation, policy-based priority, real applicant data, cloud Moodle and provider calls. Full work allocation remains blocked by institution graph and appointment authority decisions.
