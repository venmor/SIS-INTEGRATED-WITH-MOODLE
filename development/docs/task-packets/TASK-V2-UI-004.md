# TASK-V2-UI-004 — Public programme discovery

- Release: v2.0 presentation track. Lead Charles Hangoma; reviewer Chitundu Milimbo. Human visual and accessibility acceptance remains pending.
- Authority: user UI direction (2026-10-02), approved Applicant Blueprint Part 2, Section 19 UI constitution, cross-blueprint Part 2A, and ADR-003.
- Scope: make public programme search task-focused; progressively reveal detailed filters; provide actual server-backed previous/next paging; retain URL filters and comparison selection; show intake on each result; add restrained hover/focus feedback.
- Out of scope: catalogue publication, eligibility rules, new institutional branding, recommendations, provider calls, admissions decisions, or data changes.
- Acceptance: anonymous search remains available; search controls are labelled; advanced filters reopen when active; paging exposes the next result page and preserves search context; results show intake, availability, requirements and actions; 390px has no horizontal overflow; keyboard and reduced-motion interaction remain usable. Browser, web typecheck, lint and build verification must be recorded separately.
