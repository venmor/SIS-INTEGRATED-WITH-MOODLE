# Our software engineering diagrams

We include five readable engineering views inside the defence presentation under research methodology. The slides show system architecture, selected domain classes, a registration sequence, selected design classes and timetable publication. We explain selected scope and implementation limits in speaker notes.

Our presentation views have editable Graphviz sources with SVG and PNG renders. The full-reference folder retains the detailed Mermaid sources used for the report engineering views. Our selected presentation views omit secondary fields and steps for readability, and keep automatic live Moodle delivery explicitly pending.
