# How to Use the Handbook

## For report preparation

Use `01-FINAL-PROJECT-REPORT` as the ordered narrative. Cite or adapt the detailed subject documents as appendices. Add supervisor-approved academic references separately; this package does not invent citations.

## For feature planning

Start with a roadmap release, then follow this chain:

**release → requirement → role journey → screen/action → permission → state/command/event → recovery → tests → evidence**

Record the chain in a task packet. Do not ask an AI agent to read the entire repository for every task.

## For AI sessions

Load `AGENTS.md`, the task packet and only the linked controlling documents. At the end, require a completion report and an updated handoff note. A fresh agent must be able to resume without relying on the previous agent’s memory.

## For presentation

Use the three-story demonstration, architecture diagrams, policy version example, audit timeline, failure/recovery scenario, CI evidence and learning records in `13-DEMO-AND-PRESENTATION`.
