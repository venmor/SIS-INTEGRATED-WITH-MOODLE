# Role, Screen, Action and Permission Map

| Role family | Primary screen family | Representative actions | Required permission dimensions |
|---|---|---|---|
| Applicant | Public discovery, guided task form, record/status page | Start/save/submit application, upload, pay, respond, accept offer | Own person/application, state, intake, deadline |
| Student | Student home, guided registration, record/timeline | Register, pay/view account, open Moodle, view results, request support | Own record, academic period, eligibility/state |
| Lecturer/Tutor | Staff queue, course workspace, evidence review | Manage assigned teaching, stage marks, submit observation | Teaching assignment, course/TG, period, capability |
| Adviser | Work queue, student overview, observation/case page | Outreach, advise, refer, follow up | Assigned advisee/referral, purpose, case state |
| Coordinator/HoD | Programme/department overview, decision queue | Configure/propose offering, assign teaching/advisers, decide scoped exceptions | Programme/department, appointment, rule/approval state |
| Deans | Decision package, aggregate insight, delegation | Decide/refer/delegate, assign interventions | Appointment, organization, authority, conflict, time |
| Administration | Work queue, evidence/decision package, record correction | Review/verify/convert/release/award | Office role, assigned scope, separation of duties, state |
| Finance | Reconciliation queue, account/case page | Allocate, reconcile, sponsor, adjust/refund | Finance scope, amount threshold, approval state |
| Support | Restricted case, scheduling, service queue | Triage, schedule, record restricted notes, refer/close | Assignment, purpose, consent/policy, classification |
| QA/Governance | Review/evidence, finding/action, decision package | Assess, find, respond, verify, submit | Review assignment, independence, signatory authority |
| Operations | Health/incident/reconciliation queues | Configure approved change, retry/replay, recover | Environment, privileged role, change/incident approval |

Every UI permission is enforced again on the server. Hidden navigation is not authorization.
