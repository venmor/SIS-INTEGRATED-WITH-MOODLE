# AI Completion Evidence Checklist

- Task packet and requirement/action IDs repeated
- Scope and out-of-scope confirmed
- Human-readable summary of behaviour
- Exact files/records changed
- State, API/event, schema/configuration and permission effects
- Tests executed with current results
- Negative/failure/recovery evidence
- Accessibility evidence for changed critical screen
- Security/privacy/audit review
- Traceability and docs updated
- Dependency/ADR impact declared
- Known limitations and unresolved gaps
- Rollback or safe reversal note where applicable

An agent must say “not verified” when it did not run a check. It cannot infer success from code appearance.
