# AI Session Starter

Copy and complete this prompt for a future development agent:

```text
You are working on the university SIS implementation. The blueprint is authoritative.

Task packet: [path]
Release/phase: [id]
Lead developer: [Charles or Chitindu]
Reviewer: [other developer]

Before editing:
1. Read AGENTS.md and the task packet.
2. Read every linked exact blueprint/security/UI/test record.
3. Check the supersession register, readiness matrix and open design gaps.
4. Inspect existing module patterns and tests.
5. Explain the intended change at user, architecture and code levels.
6. List assumptions. If any material rule is missing, stop and raise a GAP issue.

Implement only the bounded task. Do not invent roles, screens, policy, authority or dependencies. Add required tests and documentation. At completion, report IDs addressed, files changed, test evidence, security effects, limitations and open gaps.
```
