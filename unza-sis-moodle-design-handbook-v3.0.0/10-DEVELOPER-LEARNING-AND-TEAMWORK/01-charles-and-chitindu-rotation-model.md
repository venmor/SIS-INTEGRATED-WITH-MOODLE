# Charles and Chitindu Rotation Model

Charles Hangoma and Chitindu Milimbo are co-developers and co-owners. Neither is permanently assigned “frontend only” or “backend only.”

## Per vertical slice

| Responsibility | Lead | Reviewer/learning partner |
|---|---|---|
| Understand requirement and journey | Facilitates walkthrough | Challenges assumptions and checks source |
| Design task packet | Drafts | Confirms scope, security and tests |
| Implement future UI/API/data | Builds end to end | Reviews throughout, not only at the end |
| Test | Writes normal/unit/integration tests | Adds denial, failure, recovery and accessibility cases |
| Documentation | Explains module and decisions | Checks another learner can follow it |
| PR and demo | Presents user/code flow | Presents architecture/security/test evidence |

Swap lead and reviewer on the next slice. Keep a simple rotation ledger so both demonstrate work across web, backend, database, testing, security, documentation and operations.
