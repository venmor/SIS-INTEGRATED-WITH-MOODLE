# Learning Roadmap by Phase

| Phase | Learn just before/use during | Evidence of understanding |
|---|---|---|
| Foundation | Git, terminal/WSL, TypeScript, HTTP, SQL, Docker, testing | Both create/review branches and explain the future repo |
| Identity | Sessions, hashing, cookies, guards, RBAC+scope | Explain authentication vs authorization; pass denial tests |
| Applicant | React components/forms, Next.js routing, NestJS controller/service, Prisma migration | Trace save/submit from UI to transaction/audit |
| Admissions | Queues, state machines, evidence/versioning, segregation | Explain recommendation vs decision and conflict checks |
| Registration | relational constraints, transactions, policy configuration | Explain eligibility and rollback/concurrency |
| Finance | fixed-precision money, idempotency, callbacks/reconciliation | Demonstrate uncertain payment recovery |
| Moodle | events, outbox, adapters, retries/dead letters | Demonstrate failure/replay/reconciliation |
| Results | snapshots, validation, approvals, immutable history | Explain provisional vs official result |
| Hardening | security, accessibility, observability, backup/restore | Present threat/test/incident evidence |
| Expansion | architecture evolution and regression protection | Defend why modules remain or split |

Study is tied to a real approved slice. Avoid long unrelated tutorials before the concept is needed.
