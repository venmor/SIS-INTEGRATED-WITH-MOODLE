# Roadmap Navigation

The project grows through connected releases, not by building every module at once.

| Order | Target | Primary outcome |
|---:|---|---|
| 0 | Design Gate | Confirm task-ready policies, role/action coverage and environment choices |
| 1 | `v0.1.0` | Repository, team workflow, CI, documentation and UI foundation |
| 2 | `v0.2.0` | Identity, session and scoped authorization |
| 3 | `v0.3.0` | Applicant self-service vertical slice |
| 4 | `v0.4.0` | Admissions review, decision and offer |
| 5 | `v0.5.0` | Student conversion and registration |
| 6 | `v0.6.0` | Finance simulation, payment uncertainty and clearance |
| 7 | `v0.7.0` | Moodle provisioning, failure and reconciliation |
| 8 | `v0.8.0` | Assessment staging and official result release |
| 9 | `v0.9.0` | Audit, notification, operations and presentation hardening |
| 10 | `v1.0.0-presentation` | Connected, resettable and defensible MVP |
| 11 | `v1.1`–`v1.8` | Designed module expansion families |
| 12 | `v2.0.0` | Operational completion for declared scope |

Every phase follows: **read → learn → task packets → implement vertical slices → test → document → peer review → stage/demo → release/retrospective**.
