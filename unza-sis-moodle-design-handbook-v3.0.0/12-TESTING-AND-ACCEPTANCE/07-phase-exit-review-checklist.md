# Phase Exit Review Checklist

1. Declared user outcome works end to end.
2. Requirement, role, screen, action, permission, state and test links are complete.
3. Normal, denial, failure, recovery and audit paths pass.
4. Critical screen passes accessibility/mobile checks.
5. Migration/contract/configuration versions and rollback effects are understood.
6. Security/privacy/threat review completed.
7. Demo data remains fictional and resettable.
8. Module docs, ADRs and learning notes updated.
9. Lead and reviewer both explain the seven layers.
10. Staging demonstration and retrospective completed.
11. Known limitations and next dependencies documented.
12. Release tag/note/checksum created when applicable.
