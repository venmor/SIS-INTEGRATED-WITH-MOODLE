# Demonstration Evidence Pack Checklist

- Tagged release and checksum
- Architecture/domain/integration/state diagrams
- Three scripted user journeys and fictional dataset description
- Role/permission denial demonstration
- Policy/configuration version example
- API/contract documentation snapshot
- CI pipeline results
- Unit/API/E2E/security/accessibility/recovery summary
- Audit timeline and incident/reconciliation record
- Backup/restore rehearsal evidence
- Git issues, branches, PR reviews and contribution history for both developers
- ADRs and supersession decisions
- Learning notes and rotation ledger
- Known limitations and MVP-to-completion roadmap
- Offline screenshots/recording fallback for live demo risk
