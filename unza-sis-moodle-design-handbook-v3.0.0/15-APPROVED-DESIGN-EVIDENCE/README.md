# Approved Design Evidence — Active Implementation Sources

This folder preserves the assistant-generated design outputs recovered from the shared chat. It intentionally excludes earlier implementation attachments, old research/audit files, application code and the raw conversation transcript.

- `00-generated-design-output-compendium.md` contains all 70 design outputs in chronological order without approval chatter.
- Family folders preserve each exact extracted design message plus the user responses that followed it.

These are active, approved project requirements, not retired material. Read the task-relevant individual records when designing, implementing, testing or explaining a feature. Exact approved evidence has the authority stated in [Start Here](../START-HERE.md): later approved decisions and security/privacy/official-record rules take precedence; curated summaries and examples cannot silently narrow the exact source requirements.

Use the numbered subject handbooks to navigate, then follow their source lineage to the relevant records in this folder. The [Evidence Index](EVIDENCE-INDEX.md) lists all 70 records. Load selected records completely rather than the entire compendium into every AI task. The compendium remains useful for searching provenance and cross-record questions.

The folder was renamed on 2026-09-19 at the user's request so people and AI agents recognize these requirements as part of current work. Record bodies and approval wording were preserved; [SUP-012](../90-TRACEABILITY-AND-GOVERNANCE/SUPERSESSION-REGISTER.md) documents the navigation/authority clarification.
