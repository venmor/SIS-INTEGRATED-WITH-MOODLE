# Open Production Decisions

These decisions do not block the documentation package or early demo-oriented learning, but must be resolved before the affected production task:

- Approved institutional policy values and authorities for admissions, registration, progression, results, finance, support, graduation and reporting
- Final legal/privacy/retention review
- Production hosting, availability and disaster-recovery objectives
- Identity provider/MFA and account-recovery authority
- Moodle instance/version, authentication and API scope
- Payment, notification, storage, document scanning and qualification-verification providers
- Regulatory templates, signatories and acknowledgement channels
- Monitoring, incident escalation and support ownership
- Accessibility/UAT participants and acceptance authority

Each decision becomes a versioned configuration record, ADR or approved policy reference with tests.
