# Evidence Archive

This folder preserves the assistant-generated design outputs recovered from the shared chat. It intentionally excludes earlier implementation attachments, old research/audit files, application code and the raw conversation transcript.

- `00-generated-design-output-compendium.md` contains all 70 design outputs in chronological order without approval chatter.
- Family folders preserve each exact extracted design message plus the user responses that followed it.

Use evidence to verify provenance or approval wording. Use the numbered handbook folders for normal planning and AI context loading.
